router

树路径： BurnCloud → CLI / Executables → burncloud → router

中文解释： 显式启动 Router 相关模式。

源码基线： burncloud/burncloud@aa54e21393c6d46a6b09555ffd3661c1f22484f3

End-to-End Request Flow + ICFG​

├─ Shell / OS 入口
│    └─ burncloud router
│    └─ 源码命令名为 router，但当前实现与 server 一样直接进入 run_async_server()
