burncloud price import <file>

树路径： BurnCloud → CLI / Executables → burncloud → burncloud price import <file>

中文解释： Clap 解析到 price 分支，再进入 src/cli/price.rs 中对应命令实现；参数校验失败时由 Clap/命令逻辑提前结束。

源码基线： burncloud/burncloud@aa54e21393c6d46a6b09555ffd3661c1f22484f3
