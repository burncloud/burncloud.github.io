# UI-008：建立 Console Namespace 与 Route Authorization Contract

## 第一层：人类阅读区（Human Readable Layer）

**状态：PLANNED**  
**类别：Foundation / Routing & Authorization**  
**功能依赖：UI-003、UI-007**

> 本页是 BurnCloud Console UI 路径的单一 canonical source。页面计划引用本页，不各自重新定义路径。

### TL;DR

所有需要登录、角色、tenant 或管理权限的真实生产 UI 页面都必须位于 `/console/*`。根级 `/models`、`/billing`、`/logs` 等旧 URL 最多保留为 **redirect-only compatibility stub**，不能继续渲染敏感页面或读取管理数据。

### Canonical Namespace

```text
Public              /
Data Plane          /v1/*
Management UI       /console/*
Management API      /console/api/*
Internal API        /console/internal/*
Transport           /ws
Health              /health
```

### 两条硬约束

```text
INV-UI-ROUTE-001
Protected production UI canonical URL MUST be under /console/*.

INV-UI-ROUTE-002
Legacy UI URL outside /console/* MAY only redirect.
It MUST NOT render protected content, fetch protected data, or execute management actions.
```

### 审批者关注点（Reviewer Focus）

1. 是否同意所有 authenticated UI 统一进入 `/console/*`？
2. 是否同意根级 legacy URL 只能 redirect？
3. 是否同意 URL prefix 本身绝不授予权限？
4. 是否同意 Buyer Billing 与 Admin Billing 使用独立 canonical routes？

## 第二层：机器执行层（Machine Executable Specification）

### 1. Goal

建立一个单一、可验证的 Console route namespace，并确保 root-level compatibility 不形成第二套未受控的管理页面。

### 2. Evidence

- STATIC CONFIRMED — current `app.rs` 通过 `AuthGate` 保护 `/`, `/models`, `/billing`, `/providers` 等 root-level routes。
- STATIC CONFIRMED — current `AuthGate` 只检查 authenticated。
- STATIC CONFIRMED — `API_PREFIX = /console/api`、`INTERNAL_PREFIX = /console/internal`。
- STATIC CONFIRMED — current `liveview_router()` 仍硬编码 legacy root UI paths。
- STATIC CONFIRMED — current Billing 是 authenticated user spend/usage summary，不是平台 Admin Billing。
- STATIC CONFIRMED — Target Workbench 的 `/buyer/*`、`/supplier/*`、`/admin/*` 是参考 IA，但不能直接成为 production root namespace。

### 3. Canonical Route Tree

#### Public / system

```text
/
/login
/register
/health
/ws
/v1/*
```

#### Console root

```text
/console
```

`/console` 是 authenticated workspace resolver：

```text
unauthenticated
  → /login?return_to=/console...

authenticated + one authorized workspace
  → that workspace overview

authenticated + multiple authorized workspaces
  → valid saved preference or workspace chooser

authenticated + no supported workspace
  → explicit unavailable
```

saved preference 只能在 backend-authorized roles 内选择，不能授予角色。

#### Admin Advanced / Compatibility

```text

```

它们可以暂时不出现在主 Sidebar，但不能继续以根级敏感页面形式存在。

#### Reserved backend subtrees

```text
/console/api/*
/console/internal/*
```

必须优先于 LiveView/SPA catch-all 匹配。未知 API path 必须得到 API 404/authorization semantics，而不是 Dioxus HTML。

### 4. Authorization Contract

```text
canonical /console URL
    ↓
AuthGate
    ↓
WorkspaceGate (presentation)
    ↓
Page
    ↓
Management API
    ↓
Backend role/capability/tenant authorization (final authority)
```

```text
/console/admin/* does not grant Admin
/console/supplier/* does not grant Supplier
/console/buyer/* does not bypass tenant scope
```

### 5. Billing Route Contract

Buyer 与 Admin 的 Billing 不冲突：

```text
/console/buyer/billing
= buyer-owned financial workspace

/console/admin/billing
= platform customer billing operations
```

Admin economics 保持三个独立领域：

```text
Admin Billing
≠ Admin Revenue
≠ Admin Settlements
```

- Admin Billing：customer billing / recharge / invoice / delinquency / policy / audit。
- Admin Revenue：Revenue / Verified Cost / Gross Margin。
- Admin Settlements：Supplier Payable / Settlement Batch / Payout Result。

### 6. Root Legacy Redirect Matrix

根级 legacy URL 只允许 redirect，不允许 alias 成真正业务页面、不允许读取数据、不允许调用 management API。

| Root Legacy URL | Redirect Target | 规则 |
| --- | --- | --- |
| `/dashboard` | `/console` | workspace resolver |
| `/playground` | `/console/buyer/playground` | 保持用户测试语义 |
| `/keys` | `/console/buyer/api-keys` | owner-scoped credentials |
| `/billing` | `/console/buyer/billing` | legacy user billing；**不动态跳 Admin Billing** |
| `/customers` | `/console/admin/customers` | Admin |
| `/users` | `/console/admin/customers` | Admin |
| `/models` | `/console/admin/models` | **不得变 Buyer Marketplace** |
| `/settings` | `/console/admin/settings` | legacy operational settings |
| `/providers` | `/console/admin/providers` | Advanced/Legacy Admin |
| `/routes` | `/console/admin/routes` | Advanced/Legacy Admin |
| `/guardrails` | `/console/admin/guardrails` | Advanced/Legacy Admin |
| `/evaluation` | `/console/admin/evaluation` | Advanced/Legacy Admin |
| `/team` | `/console/admin/team` | Advanced/Legacy Admin |
| `/logs` | `/console/admin/logs` | **不得变 Buyer Logs** |

`/` 的最终 Public/Home 行为是独立产品决定；authenticated Console entry 使用 `/console`。

同一个 legacy URL 不得根据当前 role 动态改变目标。例如：

```text
/billing
→ always /console/buyer/billing

NOT:
Buyer → /console/buyer/billing
Admin → /console/admin/billing
```

Admin Billing 从一开始就使用自己的 canonical `/console/admin/billing`。

### 8. Reuse Targets / Do Not Recreate

Reuse：single Dioxus Router、AuthContext/AuthGate、LiveView Router、Axum management/internal namespaces、existing redirect patterns。

Do Not Recreate：second Router、second permission DB、locale-specific route tree、root-level protected pages、role-dependent legacy URL semantics。

### 9. Scope

Allowed：canonical route enum/tree、WorkspaceGate composition、safe return_to、LiveView shell route update、reserved subtree ordering、root redirect-only stubs、tests。

Avoid：具体页面业务、backend authorization redesign、legacy feature removal、data-plane `/v1` changes。

### 10. Failure / Forbidden Fallbacks

- unauthorized workspace → explicit Forbidden/Unavailable，不 fallback Admin。
- unauthenticated → Login + safe internal `return_to`。
- unknown `/console/api/*` → API 404，不返回 UI HTML。
- unknown `/console/internal/*` → internal semantics，不返回 UI HTML。
- root legacy URL → redirect only，不能加载业务页面。

Forbidden：URL grants permission、root sensitive page、role-dependent `/models`/`/logs`/`/billing` meaning、open redirect、second Router。

### 11. Impact / Invariants

```text
public_api_cli: none
data_plane: none
frontend_routes: yes
management_api_prefix: preserved
internal_api_prefix: preserved
auth: backend final authority
```

必须保持 INV-UI-ROUTE-001 / 002、Backend Authorization final、locale-independent URL。

### 12. Dependencies

UI-003、UI-007。Role page plans inherit本合同；UI-005在 target parity 后执行 legacy redirect migration。

### 13. Stop Conditions

```text
STOP IF:
- a protected canonical page must remain outside /console/*
- compatibility requires root URL to render sensitive content
- /console UI cannot coexist safely with /console/api or /console/internal
- API/internal routes can be captured by UI catch-all
- role must be inferred from URL
- /billing must dynamically choose Buyer/Admin by active role
- data-plane /v1 behavior must change
- Web/Desktop/LiveView cannot share coherent route semantics
```

## 第三层：验收层（Definition of Done）

- [ ] `/console` 是 canonical authenticated UI root。
- [ ] Buyer/Supplier/Admin protected pages 全部位于 `/console/*`。
- [ ] Admin Billing canonical route 为 `/console/admin/billing`。
- [ ] Buyer Billing canonical route 为 `/console/buyer/billing`。

- [ ] root `/logs` 只 redirect Admin/legacy Logs，不映射 Buyer Logs。
- [ ] `/providers` `/routes` `/guardrails` `/evaluation` `/team` 真正页面迁入 `/console/admin/*`。
- [ ] 所有 root legacy URL 都是 redirect-only，无敏感业务逻辑。
- [ ] URL/Sidebar/localStorage/locale 都不能授予角色。
- [ ] Backend API authorization 仍是最终权限真相。
- [ ] `/console/api/*` 与 `/console/internal/*` 不被 UI catch-all 吞掉。
- [ ] Web/Desktop/LiveView canonical deep links + legacy redirects 一致。
- [ ] safe `return_to` 防 open redirect。
- [ ] 本 Issue 不删除 legacy business capability。
