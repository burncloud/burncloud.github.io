# UI-005：退役 Legacy Root Console Routes

## 第一层：人类阅读区（Human Readable Layer）

**状态：PLANNED**  
**类别：Route Retirement / Compatibility Cleanup**  
**功能依赖：UI-008 + 对应 `/console/*` 页面可用**

> UI-008 是路径真相。本页负责删除旧根级 Console route，而不是为它们继续维护第二套 URL surface。

### TL;DR

受保护页面迁入 `/console/*` 后，以下旧根路由直接退役，不保留页面、alias 或 redirect：

```text
/models
/logs
/providers
/routes
/guardrails
/evaluation
/team
```

对应业务能力可以继续存在于 `/console/admin/*`，但旧 URL 本身没有继续保存的必要。

### 为什么可以删除？

Current-main Evidence Audit 表明，这 7 个根路径的直接 URL 注册主要集中在 Dioxus `app.rs::Route` 与 `liveview_router()`；仓库内没有证据证明它们是稳定公共 URL/API 合同。功能测试关注的是页面能力，不要求这些 root bookmarks 永久存在。

唯一需要额外防守的是 Server 的 data-plane `fallback_service(router_app)`：删除 UI route 后，旧 URL 不能意外落入模型代理。因此退役路径必须在 data-plane fallback 前明确终止为 `404 Not Found` 或 `410 Gone`。

### 范围速览（In / Out）

| ✅ 做 | ❌ 不做 |
| --- | --- |
| 删除 7 个 root Dioxus routes | 不保留 redirect/alias |
| 删除 7 个 LiveView root shell registrations | 不把旧 URL 改成其它页面 |
| 清理 Sidebar/Search/internal links | 不删除对应业务能力 |
| root request 明确 404/410 | 不允许进入 data-plane fallback |
| 保留真正 `/console/admin/*` 页面 | 不创建第二 Router |

## 第二层：机器执行层（Machine Executable Specification）

### 1. Goal

彻底退役 `/models`、`/logs`、`/providers`、`/routes`、`/guardrails`、`/evaluation`、`/team` 七个 root-level UI routes，同时确保对应 Admin 能力只通过 `/console/admin/*` 暴露，并阻止退役 URL 落入 data-plane fallback。

### 2. Evidence

- STATIC CONFIRMED — current `crates/client/src/app.rs::Route` 注册这些 root UI routes。
- STATIC CONFIRMED — current `crates/client/src/lib.rs::liveview_router()` 也注册这些 root paths。
- STATIC CONFIRMED — `/evaluation`、`/team` 的直接 URL 依赖仅见于上述 UI route registration。
- STATIC CONFIRMED — `/logs` 的其它重要引用是 `/console/api/logs` 管理 API，不是 root `/logs` 稳定合同。
- STATIC CONFIRMED — Server 最终使用 data-plane `fallback_service(router_app)`；未匹配 root URL 不能被允许误入该 fallback。
- NOT EVIDENCED — 没有 repo evidence 证明这 7 个 root UI URL 是稳定公共兼容合同。

### 3. Entry / Starting Point

```text
crates/client/src/app.rs::Route
crates/client/src/lib.rs::liveview_router
crates/client/src/functional_layout.rs
crates/client/src/route_aliases.rs
crates/server/src/lib.rs
UI-008
```

### 4. Reuse Targets / Do Not Recreate

Reuse：single Dioxus Router、canonical `/console/admin/*` pages、existing Axum route ordering/security boundary。  
Do Not Recreate：root aliases、redirect table for retired paths、second Router、duplicate legacy pages。

### 5. Scope

Allowed：删除 root route variants/registrations、更新 links/search/tests、添加最小 retired-path rejection/tombstone 使请求在 data-plane fallback 前返回 404/410。  
Avoid：重写 Admin 页面业务、删除 `/console/admin/*` 能力、改变 `/v1/*` 语义、扩大 backend authorization。

### 6. Behavior Contract

**Inputs**：对七个 retired root paths 的 HTTP/UI request。  
**Outputs**：明确 `404` 或 `410`；不 redirect，不渲染 Dioxus protected page，不进入 data-plane。  
**Ownership**：UI-008 owns canonical routes；Server routing boundary owns retired-path termination。  
**Side Effects**：none。

```text
/models      ─┐
/logs         │
/providers    │
/routes       ├─> 404/410 before data-plane fallback
/guardrails   │
/evaluation   │
/team        ─┘
```

对应能力使用新的 canonical paths，例如：

```text
/console/admin/models
/console/admin/logs
/console/admin/providers
/console/admin/routes
/console/admin/guardrails
/console/admin/evaluation
/console/admin/team
```

### 7. Temporary Compatibility Routes

本次决策**不等于删除所有 legacy root URLs**。以下路径仍可按 UI-008 保持临时 redirect-only compatibility，直到另有明确退役决定：

```text
/dashboard   → /console
/playground  → /console/buyer/playground
/keys        → /console/buyer/api-keys
/billing     → /console/buyer/billing
/customers   → /console/admin/customers
/users       → /console/admin/customers
/settings    → /console/admin/settings
```

其中 `/billing` 始终是 Buyer legacy billing 语义；Admin Billing 独立使用 `/console/admin/billing`。

### 8. Failure / Forbidden Fallbacks

Forbidden：

```text
retired root → redirect
retired root → alias
retired root → Dioxus page
retired root → management API action
retired root → data-plane fallback
retired root → role-dependent mapping
```

若无法证明退役路径在 fallback 前终止，必须 STOP。

### 9. Impact / Invariants

```text
INV-UI-ROUTE-001
Protected canonical UI MUST live under /console/*.

INV-UI-ROUTE-002
Temporary compatibility roots, when explicitly retained, MUST be redirect-only.

INV-UI-ROUTE-003
Retired root UI paths MUST NOT exist as page, alias or redirect and MUST terminate before data-plane fallback with 404/410.
```

删除的是旧 URL surface，不是业务能力。

### 10. Dependencies

UI-008 + 对应 `/console/admin/*` canonical page availability + implementation-time internal-link audit。

### 11. Stop Conditions

```text
STOP IF:
- a retired root path can fall into router_app/data-plane fallback
- production code still links to a retired root path
- removing the route would delete the only implementation of required business capability
- a hidden external/public contract for a retired URL is discovered
- Web and LiveView cannot agree on the retired outcome
```
