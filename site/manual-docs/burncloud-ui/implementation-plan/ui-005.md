# UI-005：迁移 Legacy Console Route Compatibility

## 第一层：人类阅读区（Human Readable Layer）

**状态：PLANNED**  
**类别：Compatibility Migration**  
**功能依赖：UI-003 + 对应目标页面 parity**

### TL;DR

旧 `/providers`、`/models`、`/routes` 等不能因为新 IA 上线就一次性删除。每个 legacy route 都要先确定新 owner page、做 alias/redirect、验证 bookmark/deep link/automation，再由后续独立决策决定是否删除。

### 范围速览（In / Out）

| ✅ 做 | ❌ 不做 |
| --- | --- |
| inventory legacy routes | 不直接删 route |
| alias/redirect/unavailable matrix | 不改变 backend auth |
| role-aware safe navigation | 不复制页面内容 |
| deep-link regression | 不创建第二 Router |

### 审批者关注点（Reviewer Focus）
1. 每个旧 URL 是否有唯一行为？
2. alias 是否不会提升权限？
3. removal 是否保持为单独决策？

## 第二层：机器执行层（Machine Executable Specification）

### 1. Goal

把 legacy Console deep links 安全迁移到 Role/Page IA，同时保持 single Dioxus Router 和 backend authorization。

### 2. Evidence

- STATIC CONFIRMED — current `Route` 含 `/providers`、`/models`、`/routes`、`/playground`、`/keys`、`/customers`、`/logs`、`/billing`、`/settings` 等。
- STATIC CONFIRMED — Target implementation plan 要求 alias/redirect 后再考虑删除。
- UNKNOWN — 每个 route 的最终 mapping 必须等 target parity 与 current deep-link inventory 再确认。

### 3. Entry / Starting Point

`crates/client/src/app.rs::Route`、UI-003 workspace、已完成 target routes、internal links/search。

### 4. Reuse Targets / Do Not Recreate

Reuse：single Router、existing redirect/Link patterns、authorized workspace。  
Do Not Recreate：second Router、duplicate target pages、client role escalation。

### 5. Scope

Allowed：route inventory/mapping/redirect/alias/internal-link updates/tests。  
Avoid：page business、backend auth、route deletion。

### 6. Behavior Contract

**Inputs**：authorized roles + legacy URL + approved mapping。  
**Outputs**：safe target route、explicit unavailable/forbidden、或暂时保留 legacy behavior。  
**Ownership**：Router/Shell owns navigation；backend owns authorization。  
**Side Effects**：navigation only。

### 7. Failure / Forbidden Fallbacks

Ambiguous route 不自动去 Admin；target 未完成则按 approved matrix 保留/Unavailable。禁止删 route、复制页面、URL 获权。

### 8. Impact / Invariants

frontend navigation only；one Router；compatibility 不授予 authorization；removal = later decision。

### 9. Dependencies

UI-003 + 每个 target route/page parity + implementation-time deep-link audit。

### 10. Stop Conditions

```text
STOP IF:
- mapping requires inferred roles not granted by backend
- target page lacks parity
- deletion is required to proceed
- second Router is proposed
- query/deep-link context cannot be preserved safely
```
