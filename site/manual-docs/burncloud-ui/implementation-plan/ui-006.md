# UI-006：建立最终 UI Quality / Golden Page Gate

## 第一层：人类阅读区（Human Readable Layer）

**状态：PLANNED**  
**类别：Release Gate**  
**功能依赖：Release 页面 + UI-004、UI-005、UI-007、UI-008**

### TL;DR

最终验收不只看截图。必须同时证明数据真实、权限/tenant 隔离、`/console` 路径、legacy compatibility、i18n、完整状态、可访问性、Golden Page 视觉一致和 Web/Desktop/LiveView 可用。

### 风险与安全网（Risk）

Visual pass 不能覆盖 auth/data failure；functional pass 也不能覆盖严重 locale overflow、路径错误或 accessibility regression。

---

## 第二层：机器执行层（Machine Executable Specification）

### 1. Goal

建立一个可重复的生产 UI acceptance gate，证明 BurnCloud UI migration 的 correctness、安全性、route/i18n 稳定性和视觉质量。

### 2. Evidence

- STATIC CONFIRMED — current repo 已有 UI convention / wiring / product UX / visual-system checks。
- STATIC CONFIRMED — Dioxus 存在 Web/Desktop/LiveView 多运行形态。
- STATIC CONFIRMED — target Golden Pages 是视觉校准参考，不是业务真相。
- STATIC CONFIRMED — UI-007 定义 `en/zh/zh-TW/ja` localization；UI-008 定义 `/console/*` route/auth contract。

### 3. Entry / Starting Point

existing `crates/client/scripts/check-*.sh`、client UI workflow、target Golden Pages、UI-007、UI-008、所有 release page PR。

### 4. Reuse Targets / Do Not Recreate

Reuse：existing checks、Cargo/Dioxus build、auth/security tests、approved Golden Pages。  
Do Not Recreate：与生产脱节的第二测试体系、mock production truth、snapshot-only acceptance。

### 5. Scope

Allowed：final checks/workflows、route/auth/i18n matrix、visual QA、E2E、accessibility。  
Avoid：在本 Issue 里实现未完成页面/backend、弱化安全测试。

### 6. Behavior Contract

**Inputs**：merged production UI + approved contracts/fixtures。  
**Outputs**：明确 pass/fail evidence。  
**Ownership**：CI/checks verify；domain/backend remains truth。  
**Side Effects**：test/check definitions only。

必须覆盖交叉矩阵：

```text
role × canonical route × locale × state
```

代表性：

```text
Admin + /console/admin/revenue + zh -> allowed
Admin + /console/admin/revenue + en -> allowed
Buyer + /console/admin/revenue + zh -> forbidden
Supplier + legacy /models + en -> UI-005 approved outcome
```

### 7. Failure / Forbidden Fallbacks

任何缺失 gate 都是 failure；不得通过 disable test、mock、snapshot blessing 掩盖。语言变化不得改变 role/route 权限；Unknown 不得变 Ready。

### 8. Impact / Invariants

CI/quality only。Correctness > visual beauty。One Dioxus frontend。Backend Authorization final。Canonical `/console/*` stable。i18n 不翻译 machine identifiers。

### 9. Dependencies

UI-007、UI-008、UI-004、UI-005 + release pages DONE + approved Golden Pages。

### 10. Stop Conditions

STOP IF auth/tenant/data/route/i18n failure 被要求忽略，Golden Page 未批准，测试需要生产 mock，或 legacy compatibility 未完成。

## 第三层：验收层（Definition of Done）

- [ ] Cargo/Dioxus build 与现有 UI checks 全过。
- [ ] `/console/buyer/*`、`/console/supplier/*`、`/console/admin/*` canonical deep links 验证。
- [ ] `/console/api/*`、`/console/internal/*` 不被 UI catch-all 吞掉。
- [ ] unauthorized workspace/page access 被拒绝。
- [ ] safe `return_to` 与 login deep link 验证。
- [ ] `en/zh` 全页面关键布局无 overflow；`zh-TW/ja` Shell/关键页面 smoke 通过。
- [ ] machine identifiers/model IDs/API paths/error codes 不翻译。
- [ ] locale-aware currency/date/time/number formatting 验证。
- [ ] Loading/Empty/Partial Failure/Error/Recovered 覆盖。
- [ ] no production mock / duplicate frontend。
- [ ] keyboard/focus/non-color-only status accessibility 通过。
- [ ] Golden Page 1440×900 + narrower desktop QA 通过。
- [ ] Web/Desktop/LiveView 适用路径通过。
- [ ] UI-005 legacy compatibility matrix 通过。
- [ ] branch + PR。
