# UI-006：建立最终 UI Quality / Golden Page Gate

## 第一层：人类阅读区（Human Readable Layer）

**状态：PLANNED**  
**类别：Release Gate**  
**功能依赖：Release 页面 + UI-004、UI-005、UI-007、UI-008**

### TL;DR

最终验收必须同时证明：真实数据、权限/tenant 隔离、`/console` namespace、root redirect-only compatibility、i18n、完整状态、可访问性、Golden Page 视觉一致，以及 Web/Desktop/LiveView 深链接行为。

---

## 第二层：机器执行层（Machine Executable Specification）

### 1. Goal

建立一个可重复的 production UI acceptance gate，阻止“页面看起来完成但权限/路径/账务语义错误”的 PR 进入 main。

### 2. Evidence

- current repo 已有 UI convention/wiring/product UX/visual-system checks。
- Dioxus 有 Web/Desktop/LiveView 多运行形态。
- UI-007 定义 i18n；UI-008 定义 `/console/*` 和 root redirect-only contract。

### 3. Entry / Starting Point

existing client check scripts/workflows、security tests、UI-007、UI-008、Golden Pages、release role pages。

### 4. Reuse Targets / Do Not Recreate

Reuse existing checks/Cargo/Dioxus/auth tests。Do Not Recreate 第二测试体系、mock production truth、snapshot-only acceptance。

### 5. Scope

Allowed：final checks/workflows、route/auth/i18n matrix、visual QA、E2E、accessibility、root redirect security tests。

Avoid：在本 Issue 里补未完成 backend/page、弱化安全检查。

### 6. Behavior Contract

必须覆盖：

```text
role × canonical route × locale × state
```

并单独覆盖 root compatibility：

```text
root legacy URL
→ redirect only
→ /console/*
→ AuthGate / WorkspaceGate
→ Backend Authorization
```

Billing 代表性矩阵：

```text
Buyer + /console/buyer/billing + zh → allowed
Admin + /console/admin/billing + en → allowed
Buyer + /console/admin/billing + zh → forbidden
Admin + /console/buyer/billing + en → only if Admin also has Buyer authorization; Admin role alone does not grant Buyer workspace
/billing → /console/buyer/billing redirect only
```

### 7. Failure / Forbidden Fallbacks

任何 auth/data/route/i18n failure 都是 failure。Visual pass 不能覆盖 security/financial semantic failure。

### 8. Impact / Invariants

CI/quality only。必须验证 INV-UI-ROUTE-001 / 002、Backend Authorization final、Buyer/Admin Billing separation。

### 9. Dependencies

UI-007、UI-008、UI-004、UI-005 + required Buyer/Supplier/Admin pages + Golden Pages。

### 10. Stop Conditions

STOP IF root legacy page still renders sensitive content, role/tenant test 被要求跳过, Buyer/Admin Billing 被合并成一套权限语义, 或测试需要 production mock。

## 第三层：验收层（Definition of Done）

- [ ] Cargo/Dioxus build 与现有 UI checks 通过。
- [ ] `/console/buyer/*` `/console/supplier/*` `/console/admin/*` canonical deep links 验证。
- [ ] `/console/api/*` `/console/internal/*` 不被 UI catch-all 吞掉。
- [ ] root legacy URLs 全部只 redirect，不读取数据/执行管理动作。
- [ ] unauthorized workspace/page 被拒绝。
- [ ] safe `return_to` verified。
- [ ] Buyer Billing / Admin Billing / Revenue / Settlements 语义隔离测试。
- [ ] `en/zh` 关键页面无 overflow；`zh-TW/ja` Shell/关键页面 smoke 通过。
- [ ] machine identifiers 不翻译。
- [ ] locale-aware financial/date/number formatting 验证。
- [ ] Loading/Empty/Partial Failure/Error/Recovered 覆盖。
- [ ] no production mock / duplicate frontend。
- [ ] keyboard/focus/non-color-only accessibility 通过。
- [ ] Golden Page 1440×900 + narrower desktop QA 通过。
- [ ] Web/Desktop/LiveView + legacy redirects 一致。
- [ ] branch + PR。
