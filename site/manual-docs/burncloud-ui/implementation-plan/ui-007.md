# UI-007：建立 Production i18n / Localization Contract

## 第一层：人类阅读区（Human Readable Layer）

**状态：PLANNED**  
**类别：Foundation**  
**功能依赖：UI-001、UI-002**

### TL;DR

在任何 Buyer/Supplier/Admin 页面大规模迁移前，先建立生产 Dioxus 的统一 i18n contract。Target Workbench 已有 `en / zh / zh-TW / ja` 参考，但 Production 必须拥有自己的 translation keys、locale persistence、formatter 和 fallback，不复制 React Context 实现。

### 背景与动机（Why）

如果 25 个页面先以 hardcoded English/Chinese 完成，最后再国际化，会产生大量字符串抽取、布局回归和状态文案漂移。i18n 必须是 Foundation，而不是 release polish。

### 范围速览（In / Out）

| ✅ 做 | ❌ 不做 |
| --- | --- |
| `en/zh/zh-TW/ja` production locale contract | 不复制 React I18nContext |
| typed/stable translation keys | 不翻译 machine identifiers |
| locale preference/fallback | 不把 locale 放进 Console URL |
| number/date/currency/duration formatters | 不让每页自己 format |
| `<html lang>` / accessibility semantics | 不翻译 backend code values |
| layout QA requirements | 不在本 Issue 翻完未来所有页面 |

### 审批者关注点（Reviewer Focus）

1. Console URL 是否完全 locale-independent？
2. machine identifiers 是否保持稳定？
3. formatter 是否统一而非每页拼字符串？
4. fallback 是否不会导致空白/错误权限行为？

## 第二层：机器执行层（Machine Executable Specification）

### 1. Goal

建立生产 Dioxus localization foundation，使所有用户可见静态文案和 locale-sensitive formatting 通过统一 contract 输出，同时保持 machine values 和 Console routes 稳定。

### 2. Evidence

- STATIC CONFIRMED — Target Workbench 存在 `src/i18n/I18nContext.tsx`、typed dictionary 和 `en/zh/zh-TW/ja` locales。
- STATIC CONFIRMED — Target Workbench 通过 localStorage + browser locale 选择语言，并设置 document language；该行为只作为 Target UX evidence。
- STATIC CONFIRMED — current production Dioxus 页面仍大量 hardcode English strings/手工 currency formatting。
- STATIC CONFIRMED — BurnCloud UI 包含大量需要统一格式的 USD/CNY、Token、latency、date/time、percentage、VRAM/file-size 数据。
- UNKNOWN — Production locale preference 最终是否 server-persisted；v0.1 可先 local preference，但不能成为 authorization input。

### 3. Entry / Starting Point

```text
crates/client/src/* visible strings
crates/client/src/visual_system.css
production shared components
rustburn/burncloud-ui/src/i18n/* (reference only)
UI-002 shared component foundation
```

### 4. Reuse Targets / Do Not Recreate

Reuse：Target approved terminology、Production Dioxus context/state conventions、shared formatter utilities。  
Do Not Recreate：React I18nContext、per-page dictionaries、per-page currency/date formatter、locale-specific Router tree。

### 5. Scope

Allowed：production locale enum/context、translation dictionary/key contract、locale selector、preference/fallback、formatters、shared error/status mapping、tests。  
Avoid：URL locale prefixes、backend error-message localization architecture、page business implementation。

### 6. Behavior Contract

**Supported v0.1 locales**：

```text
en
zh
zh-TW
ja
```

**Selection precedence**：

```text
valid saved user preference
        ↓
device/browser locale
        ↓
product/deployment default
```

最终 default locale 在 READY Issue 阶段由产品配置确认；不得从个人用户上下文硬编码。

**Machine identifiers MUST NOT translate**：

```text
model IDs: qwen-4b, deepseek-v4, ...
API paths: /v1/chat/completions
error codes: MODEL_PREPARING, INSUFFICIENT_VRAM
request/channel/token IDs
currency codes: USD, CNY
technical units: TPM, RPM, TTFT, GPU, VRAM
```

UI 可翻译其说明，但不能改变机器值。

**Formatting ownership**：统一 formatter 负责 currency / number / percentage / date / time / timezone / duration / token count / byte size。

### 7. Failure / Forbidden Fallbacks

- missing translation key → deterministic fallback + dev/test signal，不得空白。
- invalid saved locale → ignore and continue fallback chain。
- locale storage failure → current session language still works。
- backend error code unknown → generic localized message + raw stable code in Details。

Forbidden：locale grants role、locale changes route、translate IDs/error codes/API paths、page-specific inconsistent formatter。

### 8. Impact / Invariants

```text
persistence: optional user/local preference only
routing: none
backend authorization: none
business data semantics: none
presentation: yes
```

Invariant：locale change must not change identity/permission/route/data query ownership。

### 9. Dependencies

UI-001、UI-002。UI-003 与 UI-008 必须消费本 contract；所有 role page plans inherit it。

### 10. Stop Conditions

```text
STOP IF:
- implementation requires locale in Console URL
- language preference becomes authorization input
- model/API/error machine identifiers must be translated
- pages need separate incompatible formatter stacks
- Target terminology conflicts with approved Product Contract
```

## 第三层：验收层（Definition of Done）

- [ ] Production 支持 `en/zh/zh-TW/ja` locale contract。
- [ ] locale selector 只改变 presentation。
- [ ] saved preference / browser fallback / default 行为可测试。
- [ ] Console URL 不包含 locale prefix。
- [ ] machine identifiers/model IDs/API paths/error codes 不翻译。
- [ ] currency/date/time/number/duration/byte formatting 统一。
- [ ] `<html lang>` 或等价 accessibility semantics 正确。
- [ ] missing key 有 deterministic fallback，不静默空白。
- [ ] zh/en Shell 与 shared components 无关键 overflow；zh-TW/ja smoke 通过。
- [ ] branch + PR。
