Windows Background Server Thread

树路径： BurnCloud → Background Jobs / Async Side Effects → Desktop Background Work → Windows Background Server Thread

中文解释： Windows 下无参数启动 burncloud.exe 时，main() 创建 std:🧵:spawn，在新 Tokio Runtime 中调用 burncloud_server::start_server(host, port, false)，同时主线程继续 launch_gui_with_tray()。

源码基线： burncloud/burncloud@aa54e21393c6d46a6b09555ffd3661c1f22484f3
