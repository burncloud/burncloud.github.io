UI-008：建立 Console Namespace 与 Route Authorization Contract

第一层：人类阅读区（Human Readable Layer）​

状态：PLANNED
类别：Foundation / Routing & Authorization
功能依赖：UI-003、UI-007

本页是 BurnCloud Console UI 路径的单一 canonical source。页面计划引用本页，不各自重新定义路径。

TL;DR​

所有需要登录、角色、tenant 或管理权限的真实生产 UI 页面必须位于 /console/*。Root-level Console 路径不再作为第二套受保护 UI surface。

Root 路径分两类：

  1. Temporary Compatibility：仍有明确迁移价值时，只允许 redirect。
  2. Retired：没有继续兼容价值时，直接删除 page / alias / redirect，并在 data-plane fallback 前明确返回 404/410。

Canonical Namespace​

Public              /
Data Plane          /v1/*
Management UI       /console/*
Management API      /console/api/*
Internal API        /console/internal/*
Transport           /ws
Health              /health

Route Invariants​

INV-UI-ROUTE-001
Protected production UI canonical URL MUST be under /console/*.

INV-UI-ROUTE-002
A root UI URL explicitly retained for temporary compatibility MAY only redirect.
It MUST NOT render protected content, fetch protected data, or execute management actions.

INV-UI-ROUTE-003
A retired root UI URL MUST NOT exist as page, alias, or redirect.
It MUST terminate with 404/410 before the data-plane fallback.

/console/* 是 namespace，不是 authorization。Backend Authorization 始终是最终权限真相。

第二层：机器执行层（Machine Executable Specification）​

1. Goal​

建立单一 /console/* 管理 UI namespace、角色级 presentation gate、Backend Authorization 边界，以及明确的 root route retention/retirement policy。

2. Evidence​

  • STATIC CONFIRMED — current app.rs 仍注册 /models、/logs、/providers、/routes、/guardrails、/evaluation、/team 等 root UI routes。
  • STATIC CONFIRMED — current liveview_router() 也硬编码这些 root paths。
  • STATIC CONFIRMED — /console/api/* 与 /console/internal/* 已是后端管理/internal namespace。
  • STATIC CONFIRMED — Server 最终使用 data-plane fallback_service(router_app)，因此删除 UI route 后必须防止 retired path 落入 fallback。
  • STATIC CONFIRMED — repo audit 未发现上述七个 root paths 被定义成稳定公共 URL/API contract；其直接 URL 依赖主要是 UI route registration。
  • STATIC CONFIRMED — current Billing 是 authenticated user spend/usage 视角；Admin Billing 是独立业务域。

4. Authorization Contract​

canonical /console URL
    ↓
AuthGate
    ↓
WorkspaceGate (presentation)
    ↓
Page
    ↓
Management API
    ↓
Backend role/capability/tenant authorization (final authority)
/console/admin/* does not grant Admin
/console/supplier/* does not grant Supplier
/console/buyer/* does not bypass tenant scope

5. Billing Route Contract​

/console/buyer/billing
= buyer balance / top-up / transactions / invoices / payment methods / spend limits

/console/admin/billing
= platform customer billing / recharge orders / delinquency / anomalies / policy / audit

/console/admin/revenue
= Revenue / Verified Cost / Gross Margin

/console/admin/settlements
= Supplier Payable / Settlement Batch / Payout Result

Invariant：

Buyer Billing
≠ Admin Billing
≠ Admin Revenue
≠ Admin Settlements

6. Root Route Policy​

A. Retired — delete completely​

以下 root paths 不保留 page、alias 或 redirect：

/models
/logs
/providers
/routes
/guardrails
/evaluation
/team

目标行为：

request
  ↓
explicit retired-path termination
  ↓
404 Not Found or 410 Gone
  ↓
STOP

MUST NOT 继续进入 router_app / data-plane fallback。

B. Temporary Compatibility — redirect-only​

以下路径可以暂时保留为无业务逻辑 redirect，直到单独退役：

Root URLTemporary Target
/dashboard/console
/playground/console/buyer/playground
/keys/console/buyer/api-keys
/billing/console/buyer/billing
/customers/console/admin/customers
/users/console/admin/customers
/settings/console/admin/settings

这些 root URLs 不得读取 protected data 或执行 management action。

/billing 始终保留 Buyer legacy billing 语义，不会因 active role 动态跳到 Admin Billing。Admin Billing 从一开始使用 /console/admin/billing。

8. Reuse Targets / Do Not Recreate​

Reuse：single Dioxus Router、AuthContext/AuthGate、LiveView Router、Axum route ordering、canonical /console/* pages。
Do Not Recreate：second Router、second permission DB、locale-specific route tree、root protected pages、redirects for retired paths。

9. Scope​

Allowed：canonical routes、WorkspaceGate composition、safe return_to、LiveView route table、reserved subtree ordering、temporary redirect stubs、retired-path 404/410 termination、targeted tests。
Avoid：具体页面业务、backend authorization redesign、删除 /console/admin/* 业务能力、改变 /v1/* 语义。

10. Failure / Forbidden Fallbacks​

Forbidden：

URL grants permission
root protected page
retired root → redirect
retired root → alias
retired root → data-plane fallback
role-dependent /billing meaning
open redirect
second Router

11. Impact / Invariants​

public_api_cli: none
data_plane_semantics: unchanged
frontend_routes: yes
server_route_ordering: retired-path safety may be required
management_api_prefix: preserved
internal_api_prefix: preserved
auth: backend final authority

必须保持 INV-UI-ROUTE-001 / 002 / 003、Backend Authorization final、locale-independent Console URL。

12. Dependencies​

UI-003、UI-007。Role page plans继承本合同；UI-005执行 root route cleanup/retirement。

13. Stop Conditions​

STOP IF:
- a protected canonical page must remain outside /console/*
- a retired root path can fall into data-plane fallback
- /console UI cannot coexist safely with /console/api or /console/internal
- API/internal routes can be captured by UI catch-all
- role must be inferred from URL
- /billing must dynamically choose Buyer/Admin by active role
- Web/Desktop/LiveView cannot share coherent route semantics

第三层：验收层（Definition of Done）​

  • /console 是 canonical authenticated UI root。
  • Buyer/Supplier/Admin protected pages 全部位于 /console/*。
  • Buyer/Admin Billing 使用独立 canonical routes。
  • /models /logs /providers /routes /guardrails /evaluation /team 无 page / alias / redirect。
  • 七个 retired roots 在 data-plane fallback 前返回 404/410。
  • /dashboard /playground /keys /billing /customers /users /settings 如暂时保留，只能 redirect-only。
  • URL/Sidebar/localStorage/locale 都不能授予角色。
  • Backend API authorization 仍是最终权限真相。
  • /console/api/* 与 /console/internal/* 不被 UI catch-all 吞掉。
  • Web/Desktop/LiveView canonical routes 与 retired outcome 一致。
  • safe return_to 防 open redirect。
  • branch + PR + route/auth/fallback regression tests。
