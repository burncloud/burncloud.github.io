# UI i18n

支持语言和格式化方法由统一 i18n 规则管理。Locale 不能决定权限，也不应进入业务路由。

以下机器标识不能翻译：模型 ID、Currency Code、状态码、request ID、TPM、RPM、TTFT、GPU、VRAM 和 API 路径。

按钮、说明、错误提示等可见文字可以翻译。金额、日期、时间、百分比、Token 和 Bytes 必须使用统一 Formatter，页面不能创建自己的语言字典和格式化算法。

正确：把 `USD` 作为机器值保存，再按 Locale 格式化显示。  
错误：把 `USD` 翻译后作为 API 参数发送。
