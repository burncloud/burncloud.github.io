**PR 说明摘要：** ## Summary Begin S0-08 by putting the local-capability attachment contract under the Traffic/Router owner instead of Platform/Node. ### Adds - `LocalRouteAttachment` DTO for an already-ready local inference endpoint - `LocalRouteAttacher` traffic-owned port - attach/detach error contract - contract test with a fake existing-router attachment adapter ### Architectural finding The existing `ModelRouter` gets candidates from the existing `channel_abilities` / `channel_providers` routing truth. `ChannelProviderModel` already owns creation/update and synchronizes channel abilities. Therefore Node must not grow a second in-memory routing table or second ModelRouter. ### Boundary Platform/Node may produce a ready local endpoint. Traffic owns whether/how that endpoint becomes routable. This PR defines that socket first; the next S0-08 implementation step should adapt it to the existing channel/provider persistence path and only emit `RouterAttached` after that operation succeeds. ### Important This PR intentionally does not yet wire the new module into the router public API or mutate production routing state. It locks the ownership and contract first so the production adapter can be implemented without pulling Traffic semantics into `platform/node`.
