**PR 说明摘要：** ## Summary Closes #474. Remove the unused Commerce / Balance quota cache surface from `burncloud-service-cache`: - `CachedQuota` and its public re-export; - quota get/set/invalidate methods; - `bc:quota:` key constant; - `CacheConfig.quota_ttl` and its default; - obsolete quota cache documentation; - the now-unused `serde::Deserialize` import. ## Boundary This is deletion only. It does not create a Balance cache and does not move balance or currency truth into Platform. Changed only: - `crates/service/crates/cache/src/service.rs` - `crates/service/crates/cache/src/lib.rs` Unchanged: - Price cache API; - Cache stats and clear behavior; - Redis connection, errors, logging, and remaining key; - Commerce/database balance and billing behavior; - Server, Client, HTTP contracts, dependencies, and directory layout. ## Verification Completed: - reconfirmed no production consumer uses the Cache Quota API; - `git diff --check main...HEAD`; - scoped diff review: 38 deletions, two replacements; - verified the Cache crate contains no `CachedQuota`, `quota_ttl`, `bc:quota:`, or quota cache method. Required before merge in a Rust-enabled environment: The current execution environment does not contain a Rust toolchain.
