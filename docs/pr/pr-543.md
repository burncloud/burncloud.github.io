Tests now consume all machine fakes through `NodeComposition`, proving each socket can be independently replaced without changing the state machine or golden-path wiring. ### Boundary - No real hardware/download/runtime/process/network implementation. - No second server/router/downloader/database. - No model/provider/router business truth added to platform. - No automatic orchestration yet; that is S0-10.
