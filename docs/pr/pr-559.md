**PR 说明摘要：** ## Traffic-owned local-vs-external preference boundary Adds the smallest policy contract needed before wiring local preference into Existing ModelRouter. ### Contract - `ExistingPolicy`: preserve current scheduler behavior across local and external candidates. - `LocalFirst`: when at least one routable local candidate exists, only the local class enters normal scheduler ranking; when none exists, external candidates remain eligible. - This policy selects a **candidate class**, not a concrete channel. - Existing health/cost/RPM/weight/affinity/failover logic remains Traffic/Scheduler responsibility. ### Boundary - Node does not decide local-vs-external preference. - No second Router, no Node state dependency, no hard-coded local channel ID. - This PR does not yet classify real Channels as Local/External or change production routing; it defines the socket and tests first. ### Evidence Tests cover existing-policy neutrality, local-first selection, external fallback, and no-candidate behavior.
