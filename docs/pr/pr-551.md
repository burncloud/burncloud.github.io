**PR 说明摘要：** ## Local capability gate Implements the framework rule: &gt; Local can run -&gt; prepare a local supply. Local cannot run -&gt; do no local work and never disturb the existing remote routing path. ### Supply contract `ModelResolver` now returns a normal `ModelResolutionOutcome`: - `Local(ResolvedModel)` — an acceptable local variant exists. - `Unsupported(LocalModelUnsupported)` — no acceptable local variant exists on this machine. `Unsupported` is deliberately not an infrastructure error. It carries a structured reason such as insufficient accelerator memory or no compatible variant. ### Application behavior `NodeOrchestrator::prepare_until_ready` now returns `LocalPreparationOutcome`. When resolution returns `Unsupported`, the orchestrator immediately stops before: - artifact preparation/download, - runtime preparation, - process spawn, - readiness work, - local route attachment. It does not mutate or replace the existing ModelRouter path. Remote Provider routing therefore remains independent and available to serve the current request. When resolution returns `Local`, the existing preparation rail continues unchanged to `Ready`; only then may the existing Traffic attachment seam add local supply. ### Boundary This PR does not implement actual hardware admission thresholds or a real model catalog.
