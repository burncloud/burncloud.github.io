                  │
                  ▼

- **弹窗、按钮和页面界面：** Console 的弹窗和页面交互被整理了。以前有些页面自己写一套弹窗，现在更多地方统一用 BCModal，关闭或保存时也把页面状态收干净。
- **数据库升级和保存数据：** SQLite 的第 0017 次数据库升级被重做了，目的是让旧数据库升级时更稳，不要因为旧表结构不同就直接出问题。
- **登录和鉴权：** 登录后的 Token 处理被统一了。现在客户端有 Token 时会带上 Bearer 头，签发和检查 JWT 也尽量走同一套密钥。 这是作者在 PR 里明确写出的修复目标。
- **监控、日志和熔断状态：** 系统记录健康状态、日志、监控或熔断信息的办法变了。它主要帮助系统知道『哪个渠道好不好用』以及管理员排查问题。
- **Console 调后台接口：** Console 页面调用后台接口的代码变了。也就是管理员点一个操作后，前端怎么请求后台发生了变化。

**真正的 BEFORE → AFTER 已经放在每个“变化块”的 plaintext 图里。不同功能不会被强行接成一条假 E2E。**
