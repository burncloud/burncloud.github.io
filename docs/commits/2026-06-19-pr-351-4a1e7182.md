## 这次主要改了什么

不要先看 17 个符号。先把这次提交当成 **2 件独立的事情** 看：**流式返回、模型请求选渠道**。

### 变化 1：流式返回

**大白话：** 流式回复不会一拿到连接就马上交给用户了。现在会先看第一块数据；如果第一块已经是上游错误，就还有机会换一个渠道。

**谁会感觉到：** 用户发起流式模型请求

#### 以前 → 现在

```text
[以前]
用户发起流式请求
   │
   ▼
上游返回一个流
   │
   ▼
马上把流交给客户端
   │
   ▼
第一块就是错误时也很难再换渠道

                 变成
                  │
                  ▼

[现在]
用户发起流式请求
   │
   ▼
上游返回一个流
   │
   ▼
先看第一块数据
   │
   ▼
第一块正常 → 继续流给用户
   │
   ▼
第一块报错 → 进入失败 / 重试处理
```

#### 这块主要改了哪些文件

- `crates/router/src/lib.rs`
- `crates/router/src/response_quality.rs`
- `crates/router/src/stream_peek.rs`

                  ▼

模型请求进来
   │
   ▼
