> **作者写的目的（AUTHOR-STATED INTENT）：** fix（router）: return JSON-formatted errors for API compatibility

> **作者补充说明（原文）：** ＃＃ 问题 之前，多个错误响应返回的是纯文本而不是 JSON 格式： - "No matching channel found for path: ..." （404） - "Unauthorized: Missing Bearer Token" （401） - "Too Many Requests" （429） - Price sync 相关错误 （503, 500, 504） 这导致 Claude Code 等客户端无法正确识别错误类型并进行重试。 ＃＃ 修复 现在所有 API 错误都返回标准的 JSON 格式： ′′′json ｛"error":｛"type":"...","message":"...","code":"...……（原 PR 里还有更多说明）
